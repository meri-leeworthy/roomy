## Proposals (ranked)

### 1. Bridge: a partial `getPublicArchivedThreads` pagination failure aborts the whole backfill, so Discord history is silently missing

- **Evidence**: `{service_name="discord-bridge"} |= "getPublicArchivedThreads failed"` = **8 events, all within 09-14T08:12–08:14Z**, two distinct causes: `RangeError: Invalid Date at toISOString` for `before=<snowflake>` and `Failed to send request to discord` for `before=-`. The handler re-throws (`discord-bridge/src/discord/live-data-source.ts:87-121`), and the caller logs `Failed to backfill archived threads for parent channel <id> in did:plc:…` (**6 events, same window**). The same run produced `Cannot resolve name for Discord channel <id> in guild 865004050357682246; skipping room creation` (**24 events**) and `Cannot resolve guildId for channel <id>; skipping backfill` (**28 events**), both `scope=backfill` — i.e. channels that get **no** Roomy room at all.
- **Why now**: this is history loss in a shipped feature, and the cause is a **one-line type conversion**. `:92-100` reads "the API accepts a snowflake or ISO8601 timestamp. Pass our snowflake as-is" then does `params.before = Number(opts.before)`. Discord's `before` wants an ISO8601 timestamp; a 19-digit snowflake passed as a JS number loses precision, normalises to an invalid Date, and `toISOString()` throws. The 09-14 burst is a single backfill run, so this recurs on every new guild backfill and every archived-thread page whose cursor is a snowflake.
- **Scope sketch**: `discord-bridge/src/discord/live-data-source.ts` — pass the cursor in the encoding Discord actually accepts (snowflake **string**, or convert to an ISO8601 timestamp) instead of `Number(...)`; stop letting `discord-bridge/src/services/backfill.ts:599` abandon the parent channel when one page fails, and make the `Cannot resolve name`/`Cannot resolve guildId` skips retryable and counted.
- **Acceptance**: a backfill of a guild with archived threads completes with zero `getPublicArchivedThreads failed` and zero `skipping backfill`; a page whose `before` is a snowflake returns threads. Regression test on the cursor conversion.
- **Suggested priority**: P1.
- **Not already tracked because**: TASK-22 (link embeds) and TASK-24 (thread system messages) are different bridge gaps; nothing in the queue covers backfill pagination or the resolution skips.
