""}"\`)` for a first path segment that is not a DID. `/home` is such a segment and there is no `/home` route (`ls packages/app-lite/src/routes` → `+layout.svelte`, `+page.svelte`, `+page.ts`, `[space]`, `build.json`, `join`, `new`, `search`, `user`). - **Why now.** It is a hard dead end for the user, on the app's own launch path, and it is not rare: 63 real-browser arrivals in 30 days, still arriving today. The fix does not depend on the cause being the manifest — a server-side redirect fixes every source of a `/home` navigation.
- **Scope sketch.** Add a `[[redirects]]` block to `netlify.toml` mapping `from = "/home"` to `to = "/"` with `status = 301`, placed above the `/*` fallback so it wins.
