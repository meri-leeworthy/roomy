## Honest limits

The bridge's death is measurable from four independent sides but its **cause is
not**: the last line is an error the code catches and logs
(`live-gateway.ts:217-226`), so the `database is locked` is not itself fatal, and
the process then emitted nothing — consistent with an OOM kill, a Railway
restart that never happened, a wedge inside the event loop, or a logging path
that died with it. No boot line, no shutdown line and no `SIGTERM` line appears
after 14:56Z, and without Railway access there is no container-level record to
consult (the same access gap that blocks TASK-462). I also cannot prove the
bridge is *dead* rather than *hung*: everything I can see is silence, which is
exactly the defect.

The published client is **bracketed, not identified**: markers put it in
[2026-10-27, 2026-11-05), but `index.html` reports `Last-Modified: Wed, 11 Nov
2026 13:56:24 GMT`, and no artifact serves a build id, so the two cannot be
reconciled. The marker test is only as good as the string surviving minification
— all six markers tested are string literals used as storage keys or log text,
which do survive, but a marker removed by a later refactor would read as an
older build than it is.

The 401 wave's endpoint is unnamed: client fetch spans carry `event_data_url.full`
as a bare origin (CF14), so "`hv.roomy.space` rejected it" is all the record
says. The 2,581/2,652 split is from a Loki hourly count, not from per-session
tracing, and Faro samples — 10 sessions and 3 users are what the sampled slice
shows, not necessarily the population.

The stall cluster's 25 h period is derived from seven clusters and I still
could not name what has that period; `db-slow` counts are a floor at a fixed
50 ms threshold, and the cluster analysis used only statements ≥ 2 s.

Production figures come from the public `/metrics` endpoint because Mimir's
single series alternates between two processes (CF26); Mimir's 1,414,389,760 B
and the live endpoint's 1,430,163,456 B differ only by scrape lag. The
`room_activity` rebuild count fell from 112 to 40 because the bridge is dead —
it is a consequence of headline 1, not an improvement.
