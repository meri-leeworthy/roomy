# Arbiter Policy

This directory contains Roomy's [arbiter] policy and test cases.

The [arbiter CLI][arbiter-cli] can be used to validate the policy, run the tests,
and generate an arbiter policy JSON record that can be uploaded to a PDS.

[arbiter]: https://github.com/muni-town/arbiter
[arbiter-cli]: https://github.com/muni-town/arbiter/tree/main/crates/arbiter-cli
